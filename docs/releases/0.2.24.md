# bbhost 日本語版 0.2.24

[上流 bbhost v0.2.24 のリリースノート](https://github.com/droogie/bbhost/releases/tag/v0.2.24)を日本語に訳し、この日本語版の配布情報を追記しています。以下の性能値は上流による測定結果です。環境によって効果は異なります。

## 上流 0.2.24 の変更

- **CPU がフレームレートの上限となる場面を高速化。** メインスレッドは描画ワーカーの処理完了を待つ間、各フレームの描画記録を手伝うようになりました。RTX 4070・1080p・フレームレート上限なしの上流テストでは、メンシスの悪夢が 94 → 100 fps、旧市街が 103 → 108 fps、聖堂街が 114 → 120 fps、ヤーナム市街が 101 → 104 fps に向上しました。60 fps では CPU 使用量が減り、Steam Deck のメンシスの悪夢では消費電力が約 0.8 W 減っています。`BBHOST_GX_BARRIER_STEAL=0` で無効にできます（[#201](https://github.com/droogie/bbhost/pull/201)）。

- **フレームレートにかかわらず血痕再生とオンライン同期を正常化。** 高リフレッシュレート画面で「画面に合わせる」を選んだ場合など、PC が選択したフレームレートを維持できないと、血痕の再生が遅くなって死亡場面の前に消えたり、ほかのプレイヤーへ自分の位置を送る頻度が下がったりしていました。両方をゲーム本来の時間に合わせ、血痕は本来の速度で最後まで再生し、キャラクターの同期は毎秒６回送信するように修正しました。PC が選択したフレームレートを維持できる場合の動作は変わりません（[#201](https://github.com/droogie/bbhost/pull/201)）。

- **キーボードとマウスの操作を改善。** 0.2.22 以降に発生していた、ダッシュ中の方向転換で減速する問題を修正しました。W+A と W+D を交互に押してもダッシュを維持し、A から D への反転ではコントローラーと同様に素早く方向転換します。保管箱の「保管箱／所持品」タブをマウスポインターで切り替えられるようになりました。ポインターが行の上にあってもホイールのスクロールが止まらず、マウスを動かすとポインター操作に戻ります（[#201](https://github.com/droogie/bbhost/pull/201)）。

- **メニュー専用のキー割り当てを追加。** `Home` / `End` で保管箱の保管品・所持品表示、`Page Up` / `Page Down` でページ、`F` / `R` で表示・ステータスを切り替えます。攻撃やアイテムのキーはメニュー内の操作に使われなくなります。従来は保管箱の「すべて取り出す」「すべて預ける」が X と V に割り当てられていました。追加したキーはすべて変更できます。`Return` はメニュー内の決定専用になりました（[#201](https://github.com/droogie/bbhost/pull/201)）。

- **実際のフレーム時間に基づく時計を設定画面から試せるように。** 設定画面と F10 の「フレームレート」の下に「実フレーム時間で動作（試験的）」を追加しました。初期状態は無効です。選択したフレームレートを維持できない PC でも、各フレームに実際にかかった時間に合わせてゲームの時間処理を行い、音声スレッドをフレームごとに起こします。変更後は再起動が必要です。上流ではこの機能の動作報告を募集しています（[#201](https://github.com/droogie/bbhost/pull/201)）。

- **修正。** 描画処理でまれにクラッシュする可能性がある問題を２件修正しました（[#201](https://github.com/droogie/bbhost/pull/201)）。

## 日本語版の配布情報

- Windows x64 / Linux x86-64 の２種類を配布します。どちらも日本版 The Old Hunters（CUSA03014）専用です。
- 新しいフレーム時計の設定、メニュー専用キーとキー設定ページの表示・説明を日本語化しています。日本語フォントを内蔵しています。
- 日本版から欧州オンラインへ接続する互換機能、再接続・プレイログ送信先の修正、ローカルトロフィーを維持しています。配布用ビルドには ThinLTO を適用しています。
- `SHA256SUMS.txt` でアーカイブの整合性を確認できます。ゲームデータ、復号済み eboot、セーブ、アカウント情報は含みません。
- 更新前にセーブをバックアップしてください。導入方法はアーカイブ内の `導入手順_日本語.md` を参照してください。
