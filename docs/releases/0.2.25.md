聖杯ボスの記録を「本編・DLC」から分離しました。「聖杯ダンジョン」で固定聖杯・汎聖杯の挑戦と撃破を確認でき、全周回の累計も独立して表示します。同じボスでもダンジョンと階層を区別し、NG+ に移るだけで同じ撃破を再加算しません。既存の本編・DLC の記録は引き続き使用できます。

NG・NG+ ごとのプレイ時間と、ボスの挑戦回数・撃破数を自動記録する「プレイ記録」を追加しました。設定画面または F9 から周回を選び、「全周回の累計を表示」でキャラクターごとの合計を確認できます。本編 17 体と DLC ５体に対応し、ボスラッシュ・練習中は通常の周回記録を一時停止します。記録開始前の情報は「不明」「以上」と表示します。詳しくは同梱の `プレイ記録.md` を参照してください。

[上流 bbhost v0.2.25](https://github.com/droogie/bbhost/releases/tag/v0.2.25)を取り込み、GPU 負荷が高いときの表示とメモリー管理を改善しました。エフェクトの時間処理を選ぶ設定と、ボスを１体ずつ練習する機能も追加しています。

- **CPU の待ち時間を削減。** フレーム終盤の描画準備を細かく分担し、メインスレッドが最後の処理を待つ時間を減らしました。CPU 側の処理がフレームレートを制限する場面に向けた改善です（[#204](https://github.com/droogie/bbhost/pull/204)）。
- **VRAM の空きが少ない環境で、不要なメモリー保持を削減。** 対象の単体 GPU で起動時に利用できる VRAM が約 7.5 GB 未満の場合、GPU が１分間使っていないメモリーを解放します。内蔵 GPU では、この自動解放は初期状態で無効です。解放は別スレッドで行い、ゲームの処理を止める時間を減らします。
- **GPU が遅れているときに、近くの物体が一瞬消える問題を修正。** 遮蔽判定に前回や別の物体の結果が使われないようにし、対応する GPU の判定結果を待つようにしました。
- **炎の照明やエフェクトの点滅を修正。** GPU の処理待ちで更新用のメモリーが足りなくなった場合、照明の更新を飛ばさず、空きができるまで待ちます。GPU が常に高負荷の場面では、この待機でフレームレートが下がる場合があります。
- **画面空間反射（SSR）パッチを更新。** 反射と深度画像の解像度、追跡設定を Kyo 版に合わせました。初期状態は無効です。設定画面の「パッチ」で選択できます（[#200](https://github.com/droogie/bbhost/pull/200)）。
- **Boss Rush にボス単体の練習を追加。** ボスを選び、１回・指定回数・停止するまでの繰り返しで挑戦できます。対応するボスは第２・第３段階から開始でき、勝敗、死亡回数、クリア時間などを記録します。補充を有効にすると毎回の挑戦前に輸血液と水銀弾を補充し、練習の終了・停止時には進行フラグを元に戻します。撃破済みのセーブでルドウイークが倒れた状態になる問題も修正しました。プラグインは初期状態では無効です。
- **設定画面の CPU 使用を抑制。** 描画は最大毎秒60回とし、最小化・非表示中は休止します。ドライバーが垂直同期を適用しない場合にも、設定画面を開いているだけで CPU を使い続ける問題を防ぎます。
- **シェーダーの「167件失敗」表示への修正を維持。** テッセレーションの評価用シェーダーを通常の頂点シェーダーとして単体処理し、`LDS use outside a compute shader` と表示していた問題を修正しています。該当する段階は「単体対象外」として分け、記録済みの描画設定の再生時や実際の描画時に、必要な組み合わせでコンパイルします。実際のシェーダー変換・パイプライン作成の失敗は引き続き表示します。

設定画面の「ゲーム」と F10 に「エフェクトの時間処理」を追加しました。変更後は再起動が必要です。30 fps を超えたときの炎・血・魔法の動きや、灯りの揺らぎを選べます。

| 設定 | 動作 |
| --- | --- |
| なめらか（初期設定） | 動きはフレームレートに合わせ、揺らぎなど回数で進める処理は原作と同じ毎秒30回に保ちます。 |
| 原作（毎秒30回） | 原作の 30 fps と同じ頻度で更新します。高フレームレートでは動きのなめらかさが下がります。 |
| 毎秒60回 | 30 fps を超える場合に毎秒60回更新します。揺らぎなど回数で進める処理は原作の２倍の速さになります。 |
| フレームレートに合わせる | １フレームに１回更新します。回数で進める処理は 60 fps で原作の２倍、120 fps で４倍の速さになります。 |

`bbhost.toml` の `[video] effect_steps` では毎秒１～960回も指定できます。`BBHOST_SFX_STEP` の指定がある場合はそちらを優先します。既存の設定値を維持しながら、選択肢と説明を日本語で表示します。

配布物は日本版 The Old Hunters（CUSA03014）専用です。Windows x64、Linux x86-64、Steam Deck の３種類を用意し、配布用ビルドには ThinLTO を適用しています。日本語フォント、プラグイン７種、日本版から欧州オンラインへ接続する互換機能、ローカルトロフィーを同梱しています。アーカイブの整合性は `SHA256SUMS.txt` で確認できます。

前回のシェーダー修正版から、変換器とキャッシュ形式は変更していません。対応する GPU ドライバーなら既存キャッシュを引き継ぎます。異なる変換器やドライバーのキャッシュは、必要に応じて再作成します。

今回の検証では Linux のネイティブ試験152件に合格し、ゲスト libc 未指定の１件をスキップしました。Windows の配布用試験11件、Linux の配布用試験20件に合格しています。ビルド環境内にゲームファイルがない２件はネイティブ試験で確認しました。各配布物の設定画面の起動・終了も確認しています。

Radeon RX 7900 XTX での事前コンパイルは失敗０件、単体対象外167件でした。短時間のオフライン起動で GPU メモリーの解放と再取り込みを確認しています。今回のローカル配布物とプラグインは未署名です。

プレイ記録の追加では、周回切替、挑戦と撃破の累計、死亡・帰還・再起動、オートセーブの巻き戻し、999 時間以降の計測、練習の除外、保存失敗・不正な記録の保護を自動テストしました。隔離したセーブのコピーを使い、実際の NG+ キャラクターで記録開始・経過時間の保存も確認しています。

聖杯の追加では、固定・汎聖杯の実行中イベントと複数の敵からなるボスの引数配置を確認し、ダンジョン・階層の区別、周回をまたぐ撃破の重複防止、独立した累計、保存・再読込をテストしました。ダンジョン移動中に前のダンジョンのイベントを転用しないようにしています。
