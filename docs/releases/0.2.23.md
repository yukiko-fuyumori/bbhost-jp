# bbhost 日本語版 0.2.23

[上流 bbhost v0.2.23 のリリースノート](https://github.com/droogie/bbhost/releases/tag/v0.2.23)を日本語に訳し、この日本語版の配布情報を追記しています。以下の性能値・検証回数は上流による測定結果です。環境によって効果は異なります。

## 上流 0.2.23 の変更

- **Linux の動作を高速化。** Linux ではゲームの描画を確定する処理を、再び１スレッドで順番に行う方式に戻しました。0.2.22 の並列確定処理は Linux では遅くなるためです。RTX 4070・1080p・フレームレート上限なしの上流テストでは、旧市街が 72 → 101 fps、メンシスの悪夢が 76 → 93 fps、カインハーストの屋根が 118 → 139 fps、ヤーナム市街が 89 → 101 fps に向上しました。Windows は並列処理のほうが速いため、その方式を維持します。`BBHOST_RUN_COMMIT=on` または `BBHOST_RUN_COMMIT=0` で切り替えられます（[#199](https://github.com/droogie/bbhost/pull/199)）。

- **CPU が処理速度の上限となる場面を高速化。** 全プラットフォームのリリースビルドにリンク時最適化（ThinLTO）を適用しました。Linux での上流測定では、CPU がボトルネックとなる場面でフレームレートが約 3〜4% 向上しています（[#199](https://github.com/droogie/bbhost/pull/199)）。

- **VRAM が 8 GB 以下の GPU でメモリー使用量を削減。** GPU はゲームのメモリーを 16 MB 単位のウィンドウ経由で読み取り、GPU 側のバッファーコピーも使用量の上限内に収めるようになりました。8 GB の RTX 3070 Ti Laptop では、共有 GPU メモリーが 4.9 GB → 1.8 GB に減り、メンシスの悪夢が 3% 高速化しました。VRAM の少ない GPU では、エリアに到着した際の引っ掛かりが減ります（[#199](https://github.com/droogie/bbhost/pull/199)）。

- **内蔵 GPU を高速化。** 後続の描画が画像を直接参照できる場合は、一部の全画面コピーを省略します。次の処理が全ピクセルを描き直す場合は、コピーを画像の入れ替えに置き換えます。Radeon 680M・1080p の上流測定では約 4〜5% 高速化し、ヤーナム市街が 33.9 → 35.5 fps になりました。内蔵 GPU では初期状態で有効です。`BBHOST_COPY_ELIDE=0` で無効にできます（[#199](https://github.com/droogie/bbhost/pull/199)）。

- **Steam Deck の GPU 停止を修正。** 0.2.19 以降、メンシスの悪夢などで到着から約１秒後に GPU が停止し、リセットされる場合がありました。GPU が読み取り中のメモリーウィンドウを切り替えてしまう問題を修正しました。上流の Steam Deck 検証では、修正前はメンシスへの到着９回中１回で停止し、修正後は14回中０回でした（[#199](https://github.com/droogie/bbhost/pull/199)）。

- **実際のフレーム時間に基づく時計を試験導入。** `BBHOST_FRAME_CLOCK=1` で有効にできます。初期状態は無効です。PC が設定したフレームレートを維持できない場合も含め、各フレームに実際にかかった時間に合わせてゲームの時間処理を行います。明暗への順応とモーションブラーが、選択したフレームレートではなく実際のフレームに追従します。フレームレート別の変換表を不要にするための最初の段階です（[#199](https://github.com/droogie/bbhost/pull/199)）。

- **Kyo 氏による 0.2.22 以降の変更。** 画面空間反射（SSR）の「Fade To Viewer」をコミュニティーパッチの値に戻し、反射の処理解像度を描画解像度の半分から同じ大きさに変更しました。反射は鮮明になりますが、GPU 負荷も増えます。Quake 0.3.16 では、大きさ・透明度を調整できる Quake 3 風の照準、Quake 3 と同じ乱数パターンの散弾と「散弾の広がり」設定を追加しました。「デバッグダッシュを復元」が有効な場合のジャンプと、はしごの上端まで登り切る動作も修正しています。設定画面と F10 に「メニューの色相」「メニューの鮮やかさ」を追加しました。「はい／いいえ」の確認画面は、開いた後に押した入力だけに即座に反応するようになりました。Quake と Lo-Hit を配布物の `plugins` フォルダーに同梱します（[#196](https://github.com/droogie/bbhost/pull/196)、[#197](https://github.com/droogie/bbhost/pull/197)）。

- **修正。** ゲーム内メニューの「フレームレート」の説明が、表示枠に収まるようになりました（[#199](https://github.com/droogie/bbhost/pull/199)）。

## 日本語版の配布情報

- Windows x64 / Linux x86-64 の２種類を配布します。どちらも日本版 The Old Hunters（CUSA03014）専用です。
- 新しい設定項目とプラグインの表示・説明を日本語化し、日本語フォントを内蔵しています。
- 日本版から欧州オンラインへ接続する互換機能、再接続・プレイログ送信先の修正、ローカルトロフィーを維持しています。
- `SHA256SUMS.txt` でアーカイブの整合性を確認できます。ゲームデータ、復号済み eboot、セーブ、アカウント情報は含みません。
- 更新前にセーブをバックアップしてください。導入方法はアーカイブ内の `導入手順_日本語.md` を参照してください。
