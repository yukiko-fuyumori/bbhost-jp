設定の引き継ぎ・保存とオンライン通信の URL 処理を修正した、bbhost 日本語版 0.2.24 の修正版です。ビルド識別子は `v0.2.24-4242f94+`、作成日は 2026年11月3日です。

- **旧設定からゲームやセーブの場所を正しく引き継ぐように修正。** 相対パスの後ろに `#` コメントがあると、設定の取り込み時にコメントや引用符までパスに含まれる場合がありました。引用符内に `#` を含むフォルダー名も正しく扱います。
- **設定の保存先とエラー処理を修正。** `settings.toml` のようにフォルダーを付けずに指定したファイルにも保存できるようになりました。既存設定の読み取り失敗を検出し、ディレクトリーなどを設定ファイルとして保存しないようにしました。書き込み終了時に発生するエラーも保存失敗として扱います。
- **起動オプションを正しく優先・検査。** `--headless` が設定ファイルの `headless = false` で上書きされる問題を修正しました。`--config`、`--app0`、`--data`、`--eboot`、`--write-config` の名前は完全一致で判定し、名前の後ろに余分な文字が付いた指定をエラーにします。
- **オンライン通信の送信先判定を修正。** 接続先の切り替えは `scej-network.jp` とそのサブドメインを対象にし、大文字・小文字の違いも扱います。末尾の文字列が似ている別ドメインを誤って切り替える問題と、パスのない URL の `?`・`#` 以降をホスト名として扱う問題を修正しました。
- **プレイログ送信先の補正条件を厳密化。** 日本版から欧州オンラインへ接続する際の補正で、ファイル名が `.` または `..` の URL を補正対象から除外しました。
- **Windows 向けテストの実行設定を整理。** Linux でクロスビルドした Windows 向けテストの Wine 設定を共通化し、新しいテストにも適用しました。今回の設定・URL 処理の修正に回帰テストを追加しています。
