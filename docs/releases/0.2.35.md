v0.2.35 日本語版です。0.2.26 から 0.2.35 までの上流変更を取り込み、日本版 The Old Hunters（CUSA03014）向けの互換処理、日本語フォント、トロフィー、プレイ履歴、聖杯履歴を維持しました。公開パッケージは Windows x64 / Linux x86-64 向けです。

## 0.2.35 の変更

- **Hunter Cam を追加**：Kyo 氏のカメラプラグインです。初期状態は無効。「プラグイン」から有効にすると肩越しの視点を使えます。Tab で肩を切替、ホイールでズーム、Z で一人称に切り替えます。一人称では腕と武器を表示し、移動方向や回避の種類も調整できます。
- **カメラとカットシーン**：Quake、Isometric、Hunter Cam はカットシーン中にゲーム側へ制御を戻します。Quake の灯り移動・ロード・死亡後のクラッシュを修正しました。併用できないカメラプラグインは設定画面に表示します。
- **低解像度でも HUD を鮮明に**：「拡大描画」が無効でも、画面より低い解像度は 3D のみに適用し、HUD・メニュー・画面効果を画面サイズに維持します。大画面では GPU 負荷が増える場合があります。上流の測定では 2560x1600 の上限なしで約 6% 増加しました。従来の挙動は `BBHOST_RENDER_SCALE=0` で使用できます。解像度一覧に縦横比を表示し、「ゲーム」の画面設定にも解像度を追加しました。
- **文字の大きさ**：「グラフィックス」でゲームの文字を 50〜100% に調整できます。メニューは開き直した時、HUD はロード後に反映します。旧 50% パッチを置き換え、使用していた場合は 50% を引き継ぎます。
- **プラグインのゲーム内メニュー**：ゲーム本来のオプション画面で設定できます。「システム」→「プラグイン」、または F10 のプラグイン欄から開きます。ロード・カットシーン・死亡時には閉じます。
- **プラグイン API 29**：ワールドの一時停止・コマ送り、プラグインごとの入力、HUD 非表示、画面効果、ゲーム本来の設定ページなど、写真モード向けの機能を追加しました。
- **CPU が制約となる場面の高速化**：上流の RTX 4070、上限なしの測定では、狩人の夢で 16〜19%、カインハーストで 14〜30% 改善しました。GPU が上限の場合などは同程度です。これらは上流の環境での測定値です。
- **設定画面と通信診断**：Discord・ウェブサイトへのボタンを追加。接続結果と対処を表示し、応答がない場合は送信と着信のどちらが届かなかったかを説明します。
- **ロード中の安定性**：GPU 停止時のログを詳しくし、上限付きで数分遊んだ後にまれに起きる画面異常・クラッシュ・GPU 停止を修正しました。
- **被写界深度**：無効時はカットシーンでも無効になり、遠景のぼかしも解像度によらず同じ見え方になります。
- **入力の独立**：各プラグインがキー・パッド・マウスを個別に扱い、操作の競合を防ぎます。リリース版で機能しなかったデバッグカメラ設定を削除しました。
- **キャッシュと保存**：上流 0.2.34 のシェーダーキャッシュを引き継げます。セーブフォルダーを Explorer で開いていると保存時に「場所が利用できません」と表示される問題を修正しました。

## 0.2.27〜0.2.34 からの主な変更

- **拡大描画と輪郭補正**：TAA、FSR 3、FSR 4、DLSS、鮮明さ、品質を追加。Linux は FSR 3 と対応する NVIDIA RTX 環境での DLSS に対応します。Steam Deck は FSR 3 に対応し、DLSS は同梱しません。FSR 4 とフレーム生成は Windows 専用です。
- **フレーム生成（Windows）**：実描画の間に１枚を生成します。HUD とメニューは補間しません。「画面に合わせる」では実描画を画面更新の半分にし、その間を補間します。ロード前後の切替や、拡大描画が無効の場合の動作も改善しました。
- **グラフィックス設定**：異方性フィルタリング、影・テクスチャ・エフェクトの品質、反射品質、高精細モーションブラー、キャラクターの動き、拡張した視野角・解像度を追加。多くをプレイ中に変更できます。
- **メニューと操作**：F10 と設定画面の構成を統一。「操作」でキー・マウス・パッドとデッドゾーンを設定できます。任意のフレームレート上限に対応し、マウス感度の範囲を拡張しました。
- **追加プラグイン**：Bloodborne PS1 と Isometric を同梱。Lo-Hit、Quake、Boss Rush も更新しました。プラグイン用のシェーダーを事前に準備し、初回のエフェクト表示の引っ掛かりを減らします。
- **追加機能**：「協力・侵入時の最大 HP」と「消耗品の自動補充」を追加。どちらも初期状態は有効で、再起動後に反映します。
- **オンライン**：現在のサーバーで協力・侵入・対人プレイを利用するには 0.2.31 以降が必要です。マルチプレイ時のキャラクター名表示、接続テスト、ログイン状態の確認を改善しました。
- **保存と終了**：セーブを一時コピーに書き込み、完了後に置き換える方式に変更。GPU ドライバーが停止した場合も、進行中の保存を待ってから終了します。
- **互換性と速度**：AVX・SSE4.2・POPCNT に対応する旧世代 CPU で不足する命令を置換。フレーム上限使用時の CPU 負荷、小容量 VRAM・内蔵 GPU、並列描画のメモリー管理を改善しました。
- **表示の修正**：移動後に消える水面、60 fps 超の一瞬のエフェクト異常、映像再生、解像度変更、輪郭補正切替時の色やメモリー使用量などを修正しました。
- **Linux の設定フォルダー**：`~/.config/bbhost` の設定を `~/.local/share/bbhost` に移します。既存の同名ファイルは上書きせず、設定画面に移動結果を表示します。
- **パッチの整理**：拡大描画・描画品質の設定に統合された旧パッチを廃止。古いフォルダーへ展開した場合も、廃止済みファイルは適用しません。DLC と全言語対応は上流で内蔵されましたが、この公開版のゲーム版制限は CUSA03014 のままです。

## この版のトロフィーと履歴

40 個のローカルトロフィー、獲得通知、NG・NG+ ごとの時間とボス戦、本編・DLC と分けた聖杯履歴を引き続き利用できます。F10 または設定画面の「トロフィー」「プレイ履歴」から開きます。F9 は同じメニューのパッチページを開きます。全周回の累計はキャラクターごとに表示します。

既存の `trophies.txt`、`play-history.txt`、`chalice-history.txt` は形式を維持しています。移行時はセーブと合わせてバックアップしてください。ボスラッシュ中の履歴停止用 API を上流 API の末尾に追加し、既存プラグインのフィールド位置を維持しました。

上流の変更一覧：[v0.2.35](https://github.com/droogie/bbhost/releases/tag/v0.2.35)、[各リリース](https://github.com/droogie/bbhost/releases)。
