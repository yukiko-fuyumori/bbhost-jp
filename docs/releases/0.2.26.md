NG・NG+ ごとのプレイ時間とボス戦の記録、シェーダーの事前コンパイル修正、描画・メモリー管理の改善をまとめた更新です。[bbhost 0.2.25](https://github.com/droogie/bbhost/releases/tag/v0.2.25) と [0.2.26](https://github.com/droogie/bbhost/releases/tag/v0.2.26) の変更を取り込み、日本語表示と既存の記録・設定を引き継ぎます。

- **周回ごとのプレイ時間を記録。** キャラクターごとに NG・NG+ の経過時間を保存します。ゲーム内のプレイ時間を基準にし、表示上限の999時間59分59秒に達した後も計測を続けます。途中から使い始めたセーブでは、記録開始前の時間や挑戦回数を「不明」「以上」と表示します。
- **ボスの挑戦回数・撃破数を確認。** 本編17体と DLC５体について、周回を選んで記録を表示できます。「全周回の累計を表示」で、そのキャラクターの合計に切り替えられます。設定画面または F9 の「プレイ記録」から開けます。詳しくは同梱の `プレイ記録.md` を参照してください。
- **聖杯ダンジョンのボスは独立して集計。** 「本編・DLC」と「聖杯ダンジョン」を切り替えて表示します。固定聖杯・汎聖杯、ダンジョンと階層を区別し、それぞれ周回別・全周回の累計を確認できます。NG+ への移行だけで過去の撃破を再加算せず、ダンジョン移動中に前の場所のボスを転用しません。
- **再開・セーブの巻き戻しに対応。** キャラクターをセーブスロットで識別し、小さなオートセーブの時間差で記録を失わないようにしました。大きく古いセーブへ戻した場合は別の履歴として扱います。本編と聖杯の記録は別ファイルに保存し、既存の本編の記録を引き継ぎます。Boss Rush の練習・ラッシュ中は通常の記録を一時停止します。
- **シェーダーの「167件失敗」を修正。** 描画の組み合わせを必要とする段階を、通常の頂点シェーダーとして誤って処理していた問題を修正しています。該当する段階は「単体対象外」と表示し、記録済みの描画設定の再生時や実際の描画時にコンパイルします。`LDS use outside a compute shader` による誤った失敗表示を解消し、実際の変換・パイプライン作成の失敗は引き続き表示します。計算シェーダーの重複集計も修正しました。
- **高フレームレートの Linux 環境で描画準備を並列化。** 16以上のハードウェアスレッドが利用でき、VRAM に余裕のある単体 GPU で60 fps を超えて動作する場合、ワーカーが先行して描画を準備します。60 fps 以下、内蔵 GPU、VRAM が少ない環境では従来の経路を使います。Windows は従来の描画経路を維持します。フレームレートは起動時に読み取るため、F10 で変更した後は再起動が必要です。効果は場面と構成によって異なります。
- **CPU の描画待ちを削減。** フレーム終盤の仕事を細かく分担し、メインスレッドが最後の処理を待つ時間を減らしました。描画用データの配置と更新の処理も改善しています。
- **GPU に合わせてメモリー保持を調整。** 対象の VRAM が少ない単体 GPU、Windows の内蔵 GPU、Steam Deck では、必要に応じて取り込んだメモリーのうち１分間使っていない領域を別スレッドで解放します。Windows の NVIDIA GPU では、再取り込みによる長い停止を避けるため保持します。既存の明示的な設定は引き続き優先します。
- **高い GPU 負荷での表示不具合を修正。** 古い遮蔽判定の結果で近くの物体が一瞬消える問題と、更新用メモリーの不足で炎の照明やエフェクトの更新が飛ぶ問題を修正しました。必要な更新を待つため、常時高負荷の場面ではフレームレートに影響する場合があります。
- **エフェクトの時間処理を選択可能。** 設定画面と F10 で「なめらか（初期設定）」「原作（毎秒30回）」「毎秒60回」「フレームレートに合わせる」を選べます。「なめらか」は動きをフレームレートに合わせ、揺らぎなど回数で進める処理を原作と同じ毎秒30回に保ちます。毎秒60回や毎フレームでは、回数に依存する処理も速くなります。変更後は再起動が必要です。`bbhost.toml` の `[video] effect_steps` では毎秒１～960回を指定でき、`BBHOST_SFX_STEP` がある場合はそちらを優先します。
- **画面空間反射（SSR）を更新。** 反射と深度画像の解像度、追跡設定を Kyo 版に合わせました。初期状態は無効で、設定画面の「パッチ」で選べます。
- **Boss Rush にボス単体の練習を追加。** １回・指定回数・停止するまでの繰り返しに対応し、対応するボスは第２・第３段階から開始できます。勝敗、死亡回数、クリア時間を記録し、任意で輸血液・水銀弾を毎回補充します。終了・停止時には進行フラグを戻し、撃破済みセーブのルドウイークが倒れた状態になる問題も修正しました。プラグインは初期状態では無効です。
- **オンライン通信の大きなデータに対応。** P2P の受信バッファ不足によるデータの取りこぼしを修正しました。大きな送信データはゲームの情報のまとまりを保って分割し、再送待ちやネットワーク上の断片化を減らします。日本版から欧州向けオンラインへ接続する互換処理と、再接続・プレイログ送信の修正も維持しています。
- **設定画面の CPU 使用を抑制。** 描画を最大毎秒60回とし、最小化・非表示中は休止します。日本語フォント、設定画面・F9/F10 の日本語表示、ローカルトロフィーの記録・通知を同梱しています。

配布物は日本版 The Old Hunters（CUSA03014）専用です。Windows x64、Linux x86-64、Steam Deck に対応し、配布用ビルドには ThinLTO を適用しています。プラグイン７種、日本語説明書、互換パックを同梱します。ゲームデータ、セーブ、アカウント情報は含みません。アーカイブの整合性は `SHA256SUMS.txt` で確認できます。

前回のシェーダー修正版から、変換器とキャッシュ形式は変更していません。対応する GPU ドライバーでは既存キャッシュを引き継ぎ、必要な場合に再作成します。今回のローカル配布物とプラグインは未署名です。

検証では Linux のネイティブ試験159件、Windows の配布用試験13件、Linux の各配布用構成で27件に合格しました。ゲスト libc 未指定の１件と、ビルド環境内にゲームファイルがない２件はスキップしています。後者はネイティブ試験で確認しています。
