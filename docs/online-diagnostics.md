# メッセージ・血痕の診断

プレイヤーのメッセージが見えない場合は、配布物のフォルダーから次の方法で起動します。

Linux:

```sh
BBHOST_ONLINE_TRACE=1 ./run-bbhost.sh
```

Windows（コマンドプロンプト）:

```bat
set BBHOST_ONLINE_TRACE=1
run-bbhost.bat
```

オンラインで問題が起きる場所を数分歩き、メッセージと血痕の表示を確認してから終了します。`logs` フォルダーの最新ログに `online-data:` の行が記録されます。診断行は取得先の種類、HTTP ステータス、エラー値、応答サイズ、所要時間を示します。認証トークン、クエリ値、応答本文は診断行に含めません。

HTTP 200 だけでは、メッセージが返されたか、画面に表示されたかは判断できません。診断ログと、試した場所・見えたものを合わせて確認します。血痕が見えることだけで協力プレイの動作確認にはなりません。

通常の起動では追加の診断記録は無効です。この診断はゲームファイルを変更しません。
