# bbhost 個人用 Linux・欧州 GOTY 互換版

この配布物は、bbhost 0.2.21 日本語版の個人用 Linux ビルドです。欧州 GOTY 版（CUSA03173、元の地域値 13）専用です。標準の Windows / Linux 配布物は日本版 Old Hunters（CUSA03014）専用であり、この版とは別の実行ファイルです。

## 起動

1. アーカイブを専用フォルダーへ展開します。
2. `./run-bbhost.sh --setup` を実行します。
3. 自分で用意した欧州 GOTY のゲームフォルダーと、復号済み更新 1.09 の eboot を指定します。
4. 設定を保存し、「プレイ」を選びます。オンラインのログインは設定画面のアカウント欄を使用します。

ゲームフォルダーには `dvdroot_ps4` と元の `sce_sys/param.sfo` が必要です。別フォルダーの更新データも欧州 GOTY 版でなければ起動できません。必要な eboot の SHA-256:

```text
941f887a562aae054fac35af8cc8f27cf075f3d4cc2e029fb5ae2a663aaa5ae7
```

EU 用の互換プラグインは同梱済み・初期状態で有効です。手動でプラグインを入れ替えたり、ゲームファイルを改変したりする必要はありません。既存設定でプラグインを無効にしていた場合は有効に戻してください。

```toml
[plugins]
region_switch = true
[region_switch]
region = "JP"
```

ここで `JP` は互換プラグインの日本語動作モードです。ゲーム版の許可条件は変わりません。プラグインは元の SFO が CUSA03173・地域値 13 であることを確認してから、実行中のみ地域値 0 の読み取り用オーバーレイ、12 個のオンライン処理の修正、× / ○ のキーボード割り当てを適用します。元のファイルは変更しません。HTTP の再接続・プレイログ補正も本体に統合済みです。

## トロフィー

本編と DLC の 40 個をローカルに記録し、日本語の獲得通知を表示します。本編の 33 個をそろえるとプラチナを自動獲得します。設定画面の「トロフィー」タブ、またはプレイ中の `F9` →「トロフィー」で確認できます。既存の `trophies.txt` は維持し、初回更新前にバックアップします。詳しくは同梱の `トロフィー.md` を参照してください。

## 操作・保存先

- `F10`: 日本語の PC 設定。0.2.21 のパフォーマンス表示も利用できます。
- `F9`: プラグイン・トロフィーメニュー。
- `Space`: 回避・ダッシュ（×）、`E`: 調べる（○）。
- 設定: 通常は `~/.config/bbhost`。
- セーブ・キャッシュ: 通常は `~/.local/share/bbhost/data`。`paths.data` の指定がある場合はそちらを使用します。

別のインストールとセーブを分けたい場合は、設定画面のデータフォルダーを別の場所に指定してください。日本語フォントは内蔵済みです。ゲーム内の素材・音声は指定したゲームデータを使用します。技術ログや外部サーバーの応答は元の表記の場合があります。

## 配布物と再ビルド

`edition.txt` が `eu-personal` のアーカイブがこの版です。通常の日本版専用配布物は `jp-only` です。設定値や環境変数で実行時に切り替えることはできません。プラグインの交換でも本体の制限は変わりません。

```sh
BBHOST_PERSONAL_EU=ON tools/linux_portable_build.sh
tools/package_linux.sh build-linux-portable/build-eu-personal/bbhost build/releases/personal-eu
tools/check_release_bundle.sh build/releases/personal-eu --allow-personal-eu
```

通常の公開用チェックは個人用 EU アーカイブを拒否します。Windows 用の EU ビルドは作成できません。ゲームファイルの識別には元の `param.sfo` のタイトル ID と地域値を使用し、全ゲームファイルの真正性を証明するものではありません。

`compat/jp-eu-v020/` には提供された互換パック全体を原本のまま保存しています。古いインストーラーをこのビルドへ実行する必要はありません。自動更新による別の版への置き換えは無効です。
