# トロフィー

日本版専用 Windows / Linux と個人用 EU Linux のすべてで、ローカルのトロフィーに対応します。本編 34 個（プラチナを含む）と The Old Hunters 6 個の計 40 個です。

ゲームが獲得を通知すると記録を保存し、日本語の通知を画面左上に約６秒間表示します。複数の獲得は順番に表示します。同じトロフィーを再取得しても取得日時や通知は重複しません。本編の 33 個をそろえるとプラチナを自動で獲得します。DLC の６個はプラチナの条件に含みません。

## 一覧

- 設定画面の「トロフィー」タブ。
- プレイ中は `F9` →「トロフィー」。`F9` または `Esc` で閉じます。

一覧には日本語の名前・条件、種類、獲得数、取得日時（UTC）を表示します。「すべて」「獲得済み」「未獲得」で絞り込めます。秘密のトロフィーは取得まで名前と条件を伏せます。「秘密の内容を表示」で確認できます。

## 記録とバックアップ

記録は設定したデータフォルダーの `trophies.txt` です。既存の bbhost の同名ファイルをそのまま読み込みます。キャラクター別ではなく、そのデータフォルダー全体で共有します。設定画面で別のデータフォルダーを選ぶと、表示する記録も切り替わります。

既存ファイルへ初めて書き込む前に `trophies.txt.pre-trophies.bak` を作成します。そのバックアップは上書きしません。新しい記録を一時ファイルへ書き込み、書き込みに成功した場合だけ置き換えます。保存に失敗した獲得を成功扱いにしたり、獲得通知を表示したりしません。保存先の空き容量と権限を確認してください。

過去の bbhost の記録に本編 33 個がそろっていれば、次のゲーム起動時のトロフィー登録でプラチナを補完します。ゲームのセーブだけから、過去に獲得したトロフィーを推定することはできません。

この機能は PC 上の記録です。PlayStation Network や Steam の実績とは同期しません。bbport / shadPS4 の記録の取り込みは今回の対象に含みません。ゲームファイルやセーブは変更しません。

## 実装の参照先

[ayozetr/bloodborne_linux](https://github.com/ayozetr/bloodborne_linux) のローカルトロフィーを参考に、この bbhost の保存・表示・HLE に合わせて実装しています。参照リビジョンは `804651e418dc1e80b1dafdc83402106bbea954cd` です。

- `scripts/trophies.py` と `src/runtime_services.c`: ID、種類、秘密の指定、DLC とプラチナの扱い。
- 同リポジトリの shadPS4 由来 `np_trophy.h` / `np_error.h`: ゲーム API の構造体配置とエラー値（GPL-2.0-or-later、shadPS4 Emulator Project）。

日本語の説明と保存・UI 処理はこの版向けです。ゲーム由来の画像や復号キーは同梱せず、通知には描画したカップのマークを使います。
